# FaceSign API — Astro + Starlight Docs Implementation Plan 🚀

> **Project root:** `facesign-all/facesign-api/astrodocs`  
> All commands assume you `cd` into that folder first.

---

## 1 · Project Overview
Create a **full-width, never-collapsed navigation** documentation portal for the FaceSign API.

| Layer | Tech | Rationale |
|-------|------|-----------|
| **SSG** | **Astro 4.x** | Lightning builds, islands architecture |
| **Docs theme** | **@astrojs/starlight** | Built-in search, i18n, dark-mode |
| **API reference** | **@starlight-openapi/plugin** | Auto-generates interactive reference from `openapi.yaml` |
| **Markup** | **MDX** | Markdown + React → shadcn components just work |
| **Styling** | **Tailwind CSS + shadcn/ui** | Familiar utilities, production-ready UI |
| **Hosting** | Vercel / Firebase Hosting | Static output, global CDN |

## 3 · Quick Start (≤ 5 min)

> **Note**: This guide assumes you're starting in the `facesign-api/astrodocs` directory which already contains the OpenAPI specification files.

```bash
# 0 · prerequisites: Node 20+, pnpm 8+, Git
# Starting from: facesign-api/astrodocs/

# Initialize Astro + Starlight in current directory
pnpm create astro@latest . --template starlight -- --install

# 1 · Add Tailwind, shadcn, and OpenAPI plugin
pnpm add @astrojs/tailwind @starlight-openapi/plugin
pnpm dlx shadcn@latest init                 # guides you through Tailwind config

# 2 · OpenAPI files are already present in astrodocs/
# - openapi.yaml          # Primary OpenAPI spec
# - openapi.json          # JSON mirror for tools
# - openapi-example.http  # REST Client examples

# Note: Copy openapi-example.http to public/ for download access
cp openapi-example.http ./public/

# 3 · Edit astro.config.mjs  (see §4)
# 4 · Run dev server on port 4001
pnpm dev --port 4001          # → http://localhost:4001
```

## 4 · Configuration Files

### 4.1 astro.config.mjs

```javascript
import { defineConfig } from 'astro/config';
import starlight from '@astrojs/starlight';
import tailwind from '@astrojs/tailwind';
import openapi from '@starlight-openapi/plugin';

export default defineConfig({
  server: {
    port: 4001,                              // set default port
  },
  integrations: [
    starlight({
      sidebar: { collapsed: false }           // never-collapse nav
    }),
    tailwind(),
    openapi({
      spec: './openapi.yaml',                 // lives in project root
      basePath: '/reference'                  // routes → /reference/*
    })
  ]
});
```

### 4.2 package.json scripts (excerpt)

```json
{
  "scripts": {
    "dev": "astro dev --port 4001",
    "build": "astro build",
    "preview": "astro preview --port 4001",
    "openapi:json": "node generate-openapi-json.js",
    "deploy:vercel": "vercel --prod",
    "deploy:firebase": "firebase deploy"
  }
}
```

Add `"postversion": "pnpm openapi:json && git add openapi.json"` to keep the JSON mirror fresh.
