# Proof of Intent Module

<div className="lead">The Proof of Intent module provides a robust, auditable way to capture a user's explicit consent or agreement to specific statements. It uses a combination of conversational AI and video recording to create a durable record of the user's intent, which is essential for legal agreements, high-value transactions, and compliance.</div>

## How it works

1. **Initiate session** - Create a session with the `proofOfIntent` module, defining the statements you need the user to agree to.
2. **Avatar presents statements** - The AI avatar clearly presents each statement to the user one by one.
3. **User agrees verbally** - The user must verbally agree to each required statement (e.g., by saying "I agree," "Yes," or "I consent").
4. **Video record created** - The entire interaction is video recorded, creating an undeniable record of the user's consent.
5. **Verification complete** - The module completes, and the results are available in the session report.

## Module configuration

### Properties

<Properties>
  <Property name="type" type="string">
    Must be `proofOfIntent`.
  </Property>
  <Property name="requestedData" type="array">
    An array of `RequestedData` objects, each representing a statement for the user to agree to.
  </Property>
</Properties>

### RequestedData object

<Properties>
  <Property name="key" type="string">
    A unique identifier for the statement. This key will be used in the `extractedData` of the session report.
  </Property>
  <Property name="description" type="string">
    The full text of the statement that will be presented to the user.
  </Property>
  <Property name="isRequired" type="boolean" optional>
    Whether the user must agree to this statement for the verification to be successful. Defaults to `true`.
  </Property>
</Properties>

## Example implementations

### Terms of service and privacy policy

Capture consent for legal agreements during user onboarding.

```typescript {{ title: 'Backend: Create session for legal consent' }}
const { session, clientSecret } = await client.sessions.create({
  clientReferenceId: 'user_123',
  modules: [
    {
      type: 'proofOfIntent',
      requestedData: [
        {
          key: 'terms_of_service',
          description: 'Do you agree to our Terms of Service?',
          isRequired: true
        },
        {
          key: 'privacy_policy',
          description: 'Do you acknowledge that you have read and understood our Privacy Policy?',
          isRequired: true
        },
        {
          key: 'marketing_emails',
          description: 'Can we send you occasional marketing emails?',
          isRequired: false // Optional consent
        }
      ]
    }
  ]
});
```

### High-value transaction confirmation

Confirm a large financial transaction to prevent disputes.

```typescript {{ title: 'Backend: Create session for transaction confirmation' }}
const { session, clientSecret } = await client.sessions.create({
  clientReferenceId: 'user_456',
  modules: [
    {
      type: 'proofOfIntent',
      requestedData: [
        {
          key: 'transaction_confirmation',
          description: 'Do you confirm that you want to transfer $10,000 to account number ending in 5678?',
          isRequired: true
        },
        {
          key: 'is_final_sale',
          description: 'Do you understand that this transaction is final and cannot be reversed?',
          isRequired: true
        }
      ]
    }
  ]
});
```

## Handling verification results

### Webhook event

The `session.completed` webhook report contains the user's responses in the `extractedData` field. The video recording is also available for audit purposes.

```json {{ title: 'session.completed webhook payload' }}
{
  "id": "evt_abc123",
  "type": "session.completed",
  "data": {
    "session": {
      "id": "fs_session_xyz789",
      "status": "complete",
      "report": {
        "isVerified": true, // True if all required statements were agreed to
        "videos": {
          "userVideoUrl": "https://cdn.facesign.ai/videos/fs_session_xyz789.mp4"
        },
        "extractedData": {
          "terms_of_service": "true",
          "privacy_policy": "true",
          "marketing_emails": "false"
        }
      },
      "settings": {
        "clientReferenceId": "user_123"
      }
    }
  }
}
```

### Backend logic

Use the webhook to record the user's consent and proceed with the action they agreed to.

```typescript {{ title: 'Backend: Webhook handler' }}
app.post('/webhooks/facesign', async (req, res) => {
  const { type, data } = req.body;

  if (type === 'session.completed' && data.session.report?.isVerified) {
    const { session } = data;
    const { report, settings } = session;
    const { extractedData } = report;
    const userId = settings.clientReferenceId;

    if (extractedData?.terms_of_service === 'true' && extractedData?.privacy_policy === 'true') {
      // Record consent in your database
      await db.consent.create({
        data: {
          userId,
          termsOfServiceVersion: 'v2.1',
          privacyPolicyVersion: 'v1.8',
          agreedAt: new Date(),
          videoProofUrl: report.videos.userVideoUrl
        }
      });

      // Activate the user's account
      await activateUserAccount(userId);
    }
  }

  res.status(200).send('OK');
});
```

## Best practices

### 1. Clear and concise statements

Phrase your statements as clear, unambiguous yes/no questions. Avoid legal jargon where possible.

### 2. Required vs. optional consent

Carefully distinguish between required agreements (like terms of service) and optional ones (like marketing consent) using the `isRequired` flag.

### 3. Audit trail

Store the `userVideoUrl` from the session report as part of your audit trail. This provides irrefutable proof of consent.

### 4. Combine with Identity Verification

For maximum legal protection, combine `proofOfIntent` with `identityVerification` and `documentAuthentication` to prove not only *what* was agreed to, but also *who* agreed to it.

```typescript {{ title: 'Backend: High-assurance consent flow' }}
const { session, clientSecret } = await client.sessions.create({
  clientReferenceId: 'user_123',
  modules: [
    { type: 'identityVerification' },
    { type: 'documentAuthentication' },
    {
      type: 'proofOfIntent',
      requestedData: [
        // ... your statements
      ]
    }
  ]
});
```
