# Quick Start

This quickstart shows a minimal 3-step Dev flow to get a hosted verification session running. {{ className: 'lead' }}

<Note>
  Keep your API keys server-side and use environment variables.
</Note>

## Step 1 — Install and set your API key

Get your key from the FaceSign dashboard (Settings → API Keys). Set it for local use:

<CodeGroup>

```bash {{ title: '.env' }}
FACESIGN_API_KEY=sk_test_...
```

```bash {{ title: 'JavaScript (optional SDK)' }}
yarn add @facesignai/api
```

```bash {{ title: 'Python (optional SDK)' }}
pip install facesignai
```

</CodeGroup>

## Step 2 — Create a session (Dev)

POST to Dev with a minimal flow (`start` → `end`).

<CodeGroup title="Create a session" tag="POST" label="/sessions (Dev)">

```bash {{ title: 'cURL' }}
curl -X POST https://api.dev.facesign.ai/sessions \
  -H "Authorization: Bearer $FACESIGN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "clientReferenceId": "user-123",
    "metadata": { "source": "quickstart" },
    "flow": {
      "nodes": [
        { "id": "start", "type": "start" },
        { "id": "end", "type": "end" }
      ],
      "edges": [
        { "id": "e1", "source": "start", "target": "end" }
      ]
    }
  }'
```

```typescript {{ title: 'TypeScript (fetch)' }}
const res = await fetch('https://api.dev.facesign.ai/sessions', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.FACESIGN_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    clientReferenceId: 'user-123',
    metadata: { source: 'quickstart' },
    flow: {
      nodes: [
        { id: 'start', type: 'start' },
        { id: 'end', type: 'end' }
      ],
      edges: [
        { id: 'e1', source: 'start', target: 'end' }
      ]
    }
  }),
})
const { session, clientSecret } = await res.json()
console.log('Session ID:', session.id)
console.log('Hosted URL:', clientSecret.url)
```

```python {{ title: 'Python (requests)' }}
import os, requests

payload = {
  "clientReferenceId": "user-123",
  "metadata": { "source": "quickstart" },
  "flow": {
    "nodes": [
      { "id": "start", "type": "start" },
      { "id": "end", "type": "end" }
    ],
    "edges": [
      { "id": "e1", "source": "start", "target": "end" }
    ]
  }
}
r = requests.post(
  'https://api.dev.facesign.ai/sessions',
  json=payload,
  headers={'Authorization': f'Bearer {os.environ.get("FACESIGN_API_KEY","")}'}
)
data = r.json()
print('Session ID:', data['session']['id'])
print('Hosted URL:', data['clientSecret']['url'])
```

</CodeGroup>

## Step 3 — Open the hosted URL

Send your user to the `clientSecret.url` to complete verification.

## Retrieve the session (optional)

Use the session ID to poll status or fetch results.

<CodeGroup title="Retrieve a session" tag="GET" label="/sessions/{id} (Dev)">

```bash {{ title: 'cURL' }}
curl https://api.dev.facesign.ai/sessions/sess_abc123 \
  -H "Authorization: Bearer $FACESIGN_API_KEY"
```

```typescript {{ title: 'TypeScript (fetch)' }}
const res = await fetch('https://api.dev.facesign.ai/sessions/sess_abc123', {
  headers: { Authorization: `Bearer ${process.env.FACESIGN_API_KEY}` },
})
const { session } = await res.json()
console.log('Status:', session.status)
```

```python {{ title: 'Python (requests)' }}
import os, requests
r = requests.get(
  'https://api.dev.facesign.ai/sessions/sess_abc123',
  headers={'Authorization': f'Bearer {os.environ.get("FACESIGN_API_KEY","")}'}
)
print(r.json()['session']['status'])
```
