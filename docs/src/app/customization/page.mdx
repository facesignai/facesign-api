# Session Customization

<div className="lead">Tailor the FaceSign verification experience to match your brand and user experience requirements. Customize UI elements, colors, text, and behavioral aspects of the verification flow.</div>

## Overview

FaceSign provides extensive customization options to ensure the verification experience seamlessly integrates with your application. You can customize:

- **Permissions page** - Landing page appearance and messaging
- **UI controls** - Show/hide interface elements
- **Text and messaging** - Custom labels and instructions
- **Multi-language support** - Localized text for different languages

## Customization Structure

Customizations are defined using the `Customization` interface and passed when creating sessions:

```typescript {{ title: 'Customization interface' }}
interface Customization {
  permissionsPage?: PermissionsPageCustomization
  controls?: ControlsCustomization
}
```

## Basic Customization Example

```typescript {{ title: 'Basic customization' }}
const customization = {
  permissionsPage: {
    buttonText: 'Start Verification',
    backgroundType: 'COLOR',
    backgroundColor: '#1a202c',
    mainHeading: 'Identity Verification Required',
    subheading: 'We need to verify your identity to continue with your application.'
  }
}

const { session, clientSecret } = await client.sessions.create({
  clientReferenceId: 'user_123',
  modules: [
    { type: 'emailVerification' },
    { type: 'identityVerification' }
  ],
  customization
})
```
