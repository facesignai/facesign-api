# Session Customization

Customize the FaceSign verification permissions page and UI controls to match your brand and user experience requirements. {{ className: 'lead' }}

## Overview {{ anchor: false }}

FaceSign provides customization options for the permissions page shown before verification begins and global UI control settings. Customizations are applied when creating a session.

<Note>
  Customizations are optional. If not provided, FaceSign uses sensible defaults with your configured avatar.
</Note>

---

## Permissions Page

The permissions page appears before verification starts, requesting camera/microphone access. Customize text, background, and button appearance.

### Available Options

<Properties>
  <Property name="buttonText" type="string">
    Text displayed on the start button (e.g., "Begin Verification"). Defaults to "Continue".
  </Property>
  <Property name="mainHeading" type="string">
    Primary heading text shown at the top of the permissions page.
  </Property>
  <Property name="subheading" type="string">
    Secondary text providing additional context below the main heading.
  </Property>
  <Property name="backgroundType" type="enum">
    Background display type: `"AVATAR"` (show avatar video) or `"COLOR"` (solid color). Defaults to `"AVATAR"`.
  </Property>
  <Property name="backgroundColor" type="string">
    Background color when `backgroundType` is `"COLOR"`. Hex or CSS color string (e.g., `"#f0f0f0"`).
  </Property>
</Properties>

<SimpleCodeBlock title="Permissions Page Customization" language="json" variant="light" code={`{
  "permissionsPage": {
    "mainHeading": "Identity Verification",
    "subheading": "We need camera access to verify your identity",
    "buttonText": "Start Verification",
    "backgroundType": "COLOR",
    "backgroundColor": "#1a202c"
  }
}`}/>

---

## UI Controls

Global UI control settings that apply throughout the verification session.

### Available Options

<Properties>
  <Property name="showUxControls" type="boolean">
    Show or hide UX control elements during verification. Defaults to `true`.
  </Property>
</Properties>

<SimpleCodeBlock title="UI Controls Customization" language="json" variant="light" code={`{
  "controls": { "showUxControls": false }
}`}/>

---

## Multi-language Support

Permissions page text can be translated for multi-language sessions. Provide translations as key-value pairs where keys are language codes.

### Translation Fields

<Properties>
  <Property name="buttonTextTranslates" type="object">
    Translations for button text. Keys are language codes (e.g., `"es"`, `"fr"`).
  </Property>
  <Property name="mainHeadingTranslates" type="object">
    Translations for main heading.
  </Property>
  <Property name="subheadingTranslates" type="object">
    Translations for subheading.
  </Property>
</Properties>

<Note>
  Use with the `langs` and `defaultLang` session parameters to enable language switching. See [Sessions](/sessions) for details.
</Note>

<SimpleCodeBlock title="Multi-language Example" language="json" variant="light" code={`{
  "permissionsPage": {
    "mainHeading": "Identity Verification",
    "mainHeadingTranslates": { "es": "Verificación de Identidad", "fr": "Vérification d'identité" },
    "subheading": "Camera access required",
    "subheadingTranslates": { "es": "Se requiere acceso a la cámara", "fr": "Accès à la cámara requis" },
    "buttonText": "Continue",
    "buttonTextTranslates": { "es": "Continuar", "fr": "Continuer" }
  }
}`}/>

## Common Examples

### Minimal Branding

Customize just the heading and button text:

<SimpleCodeBlock title="Minimal Setup" language="json" variant="light" code={`{
  "customization": { "permissionsPage": { "mainHeading": "Welcome to SecureBank", "buttonText": "Get Started" } }
}`}/>

### Avatar Background

Use avatar video as background (default behavior):

<SimpleCodeBlock title="Avatar Background" language="json" variant="light" code={`{
  "avatarId": "June_HR_public",
  "customization": { "permissionsPage": { "backgroundType": "AVATAR", "mainHeading": "Let's verify your identity", "buttonText": "Start" } }
}`}/>

### Color Background

Use a solid color instead of avatar video:

<SimpleCodeBlock title="Color Background" language="json" variant="light" code={`{
  "customization": {
    "permissionsPage": {
      "backgroundType": "COLOR",
      "backgroundColor": "#0f172a",
      "mainHeading": "Identity Verification Required",
      "subheading": "We'll guide you through the process",
      "buttonText": "Continue"
    }
  }
}`}/>

### Bilingual Session

Support English and Spanish:

<SimpleCodeBlock title="Bilingual Setup" language="json" variant="light" code={`{
  "langs": ["en", "es"],
  "defaultLang": "en",
  "customization": {
    "permissionsPage": {
      "mainHeading": "Verification",
      "mainHeadingTranslates": { "es": "Verificación" },
      "buttonText": "Start",
      "buttonTextTranslates": { "es": "Comenzar" }
    }
  }
}`}/>

<Note>
  Test your customizations across different devices and screen sizes to ensure a consistent user experience.
</Note>
