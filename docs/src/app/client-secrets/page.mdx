# Client Secrets

Client secrets are secure, session-specific tokens that allow your end users to access FaceSign's hosted verification interface. Unlike your API key, client secrets are safe to expose in URLs and are automatically included when you create a session. {{ className: 'lead' }}

## How client secrets work

Client secrets provide a secure way to redirect users to the verification flow:

1. **Server-side session creation** - Use your API key to create a session on your backend
2. **Client secret returned** - FaceSign returns a session-specific client secret with embedded URL
3. **Redirect users** - Redirect your end users to the `clientSecret.url` to begin verification
4. **Hosted verification** - Users complete verification on FaceSign's hosted interface
5. **Automatic expiration** - Client secrets expire after 2 hours for security

## Client secret properties

<Properties>
  <Property name="secret" type="string">
    The client secret token to use in frontend integrations.
  </Property>
  <Property name="createdAt" type="number">
    Unix timestamp when the client secret was created.
  </Property>
  <Property name="expireAt" type="number">
    Unix timestamp when the client secret expires (2 hours from creation).
  </Property>
  <Property name="url" type="string">
    Pre-built URL for hosted verification flow including the client secret.
  </Property>
</Properties>

## Creating sessions with client secrets

Use your backend SDK to create a session and get the client secret URL:

<CodeGroup title="Backend: Create session">

```typescript {{ title: 'TypeScript' }}
import Client from '@facesignai/api'
import { FSNodeType } from '@facesignai/api'

const client = new Client({
  auth: process.env.FACESIGN_API_KEY,
  serverUrl: 'https://api.dev.facesign.ai'
})

const { session, clientSecret } = await client.session.create({
  clientReferenceId: 'user-123',
  metadata: {
    userId: '123',
    source: 'web-app'
  },
  flow: {
    nodes: [
      { id: 'start', type: FSNodeType.START, outcome: 'liveness' },
      { id: 'liveness', type: FSNodeType.LIVENESS_DETECTION, outcomes: {
        livenessDetected: 'end',
        deepfakeDetected: 'end',
        noFace: 'end'
      }},
      { id: 'end', type: FSNodeType.END }
    ],
    edges: [
      { id: 'e1', source: 'start', target: 'liveness' },
      { id: 'e2', source: 'liveness', target: 'end' }
    ]
  },
  avatarId: 'June_HR_public'
})

// Client secret structure:
// {
//   secret: "csea61d44d88d345e1b91622820bb73100",
//   createdAt: 1761001508335,
//   url: "https://session.dev.facesign.ai?cs=csea61d44d88d345e1b91622820bb73100",
//   expireAt: 1761008708335
// }
```

## Redirecting users to verification

Once you have the client secret, redirect your users to the hosted verification interface:

<CodeGroup title="Frontend integration">

```typescript {{ title: 'Express.js' }}
app.get('/start-verification', async (req, res) => {
  // Create session on backend
  const { session, clientSecret } = await client.session.create({
    clientReferenceId: req.user.id,
    metadata: { userId: req.user.id },
    flow: { nodes: [...], edges: [...] }
  })

  // Redirect user to hosted verification
  res.redirect(clientSecret.url)
  // URL: https://session.dev.facesign.ai?cs=csea61d44d88d345e1b91622820bb73100
})
```

```typescript {{ title: 'Next.js API Route' }}

    auth: process.env.FACESIGN_API_KEY,

  })

    clientReferenceId: 'user-123',
    metadata: {},
    flow: { nodes: [...], edges: [...] }
  })

  // Redirect to hosted verification
  return Response.redirect(clientSecret.url)
}
```


## Security considerations

### Client secrets are safe for frontend use

Unlike API keys, client secrets are designed to be safe for URL exposure:

- **Session-specific** - Each client secret is tied to a single session
- **Time-limited** - Automatically expire after 2 hours
- **Read-only** - Cannot be used to create new sessions or access other data
- **URL-based** - Embedded in the verification URL for easy redirection

### Best practices

1. **Fetch on demand** - Get client secrets from your backend when needed
2. **Handle expiration** - Refresh client secrets if they expire during verification
3. **Secure transmission** - Always use HTTPS when transmitting client secrets
4. **Don't store long-term** - Client secrets are meant for immediate use

<CodeGroup title="Secure implementation">

```typescript {{ title: 'Backend endpoint' }}
import Client from '@facesignai/api'
import { FSNodeType } from '@facesignai/api'

const client = new Client({
  auth: process.env.FACESIGN_API_KEY,
  serverUrl: 'https://api.dev.facesign.ai'
})

// Secure endpoint to create sessions
app.post('/api/create-verification', authenticate, async (req, res) => {
  // Verify user is authenticated
  if (!req.user) {
    return res.status(401).json({ error: 'Unauthorized' })
  }

  try {
    const { session, clientSecret } = await client.session.create({
      clientReferenceId: req.user.id,
      metadata: {
        userId: req.user.id,
        email: req.user.email,
        ipAddress: req.ip
      },
      flow: {
        nodes: [
          { id: 'start', type: FSNodeType.START, outcome: 'liveness' },
          { id: 'liveness', type: FSNodeType.LIVENESS_DETECTION, outcomes: {
            livenessDetected: 'end',
            deepfakeDetected: 'end',
            noFace: 'end'
          }},
          { id: 'end', type: FSNodeType.END }
        ],
        edges: [
          { id: 'e1', source: 'start', target: 'liveness' },
          { id: 'e2', source: 'liveness', target: 'end' }
        ]
      }
    })

    // Store session in your database
    await db.verifications.create({
      sessionId: session.id,
      userId: req.user.id,
      status: session.status,
      createdAt: new Date()
    })

    // Return client secret URL to frontend
    res.json({
      verificationUrl: clientSecret.url,
      sessionId: session.id
    })

  } catch (error) {
    console.error('Session creation failed:', error)
    res.status(500).json({ error: 'Failed to create verification session' })
  }
})
```

```typescript {{ title: 'Frontend implementation' }}
async function startVerification() {
  try {
    // Fetch verification URL from your secure backend
    const response = await fetch('/api/create-verification', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${userToken}`,
        'Content-Type': 'application/json'
      }
    })

    if (!response.ok) {
      throw new Error('Failed to create verification session')
    }

    const { verificationUrl, sessionId } = await response.json()

    // Redirect to hosted verification
    window.location.href = verificationUrl
    // URL: https://session.dev.facesign.ai?cs=csea61d44d88d345e1b91622820bb73100

  } catch (error) {
    console.error('Verification startup failed:', error)
    showErrorMessage('Unable to start verification')
  }
}
```

### Handling expiration

Client secrets expire after 2 hours. If you need to refresh a client secret for an existing session:

```typescript {{ title: 'Refresh client secret' }}
import Client from '@facesignai/api'

const client = new Client({
  auth: process.env.FACESIGN_API_KEY,
  serverUrl: 'https://api.dev.facesign.ai'
})

// Backend endpoint for refreshing client secret
app.post('/api/refresh-verification/:sessionId', authenticate, async (req, res) => {
  const { sessionId } = req.params

  // Verify the session belongs to the authenticated user
  const verification = await db.verifications.findFirst({
    where: { sessionId, userId: req.user.id }
  })

  if (!verification) {
    return res.status(404).json({ error: 'Session not found' })
  }

  try {
    // Generate new client secret for existing session
    const clientSecret = await client.session.createClientSecret({ sessionId })

    res.json({
      verificationUrl: clientSecret.url
    })

  } catch (error) {
    console.error('Failed to refresh client secret:', error)
    res.status(500).json({ error: 'Failed to refresh client secret' })
  }
})
```

```typescript {{ title: 'Frontend: Handle expiration' }}
async function handleClientSecretExpiration(sessionId: string) {
  try {
    // Call your backend to refresh the client secret
    const response = await fetch(`/api/refresh-verification/${sessionId}`, {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${userToken}`
      }
    })

    const { verificationUrl } = await response.json()

    // Redirect to updated verification URL
    window.location.href = verificationUrl

  } catch (error) {
    console.error('Failed to refresh client secret:', error)
    window.location.href = '/start-verification'
  }
}
```
