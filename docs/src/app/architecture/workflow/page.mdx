## Phase 1: Design Your Flow

### Access Flow Designer

First, get access to the Flow Designer (Sandbox):

1. **Request Access**: Contact FaceSign admin for provisioning
2. **Login**: Access at https://create.facesign.ai
3. **Get API Key**: Find your test key in Settings → API Keys

### Create Your Verification Flow

Use the visual interface to design your flow:

- **Drag and drop** verification nodes onto the canvas
- **Connect nodes** with edges to define the flow
- **Configure each node** with specific parameters
- **Set conditions** for branching logic

## Best Practices

### Development Best Practices

- **Always start in Sandbox** - Never test with real PII
- **Version your flows** - Keep track of changes
- **Document decisions** - Why certain nodes/conditions were chosen
- **Test edge cases** - Don't just test the happy path
- **Review security** - Before each production deployment

### Production Best Practices

- **Implement retry logic** - Handle transient failures
- **Log comprehensively** - But never log PII
- **Monitor actively** - Set up dashboards and alerts
- **Plan for scale** - Test load before peak usage
- **Maintain compliance** - Regular audits and reviews
