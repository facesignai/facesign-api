## How It Works

### 1. Design Phase (Sandbox)
Use the Flow Designer to visually create and test your verification flows with sample data. This environment is perfect for:
- Prototyping user journeys
- Testing different verification combinations
- Creating demos for stakeholders
- Training team members

### 2. Implementation Phase
Export your flow configuration from the Sandbox and implement it in your application:
- Use the FaceSign SDK in your codebase
- Configure flows programmatically
- Set up your infrastructure

### 3. Production Phase
Deploy and run verifications in your environment:
- All data stays in your systems
- FaceSign API processes verification logic
- You maintain complete control and compliance
