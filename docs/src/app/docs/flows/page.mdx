## Concepts

A flow defines the ordered (or conditional) nodes a user must complete (e.g., Email, Document, Liveness).

## Create a flow

<CodeTabs codeExamples={{
  curl: 'curl -X POST https://api.dev.facesign.ai/flows \\\n  -H "Authorization: Bearer YOUR_API_KEY" \\\n  -H "Content-Type: application/json" \\\n  -d @flow.json',
  javascript: 'await fs.flows.create({ id: "flow_basic", nodes: [ { type: "enter_email" }, { type: "document_scan" } ] })',
}} />

## Get a flow

<CodeTabs codeExamples={{
  curl: 'curl https://api.dev.facesign.ai/flows/flow_basic -H "Authorization: Bearer YOUR_API_KEY"',
  javascript: 'await fs.flows.get("flow_basic")',
}} />

## FSNode object

### Node types

<Properties>
  <Property name="type" type="enum">
    One of `start`, `end`, `conversation`, `liveness_detection`, `enter_email`, `data_validation`, `document_scan`, `recognition`, `face_scan`, `two_factor`.
  </Property>
  <Property name="id" type="string">Unique identifier within the flow.</Property>
</Properties>

### Minimal flow JSON

<SimpleCodeBlock
  title="Minimal FSFlow"
  language="json"
  code={`{
  "nodes": [
    { "id": "start", "type": "start", "outcome": "conv1" },
    { "id": "conv1", "type": "conversation", "prompt": "Hello!", "transitions": [{ "id": "any", "condition": "true" }] },
    { "id": "end", "type": "end" }
  ],
  "edges": [
    { "id": "e1", "source": "start", "target": "conv1" },
    { "id": "e2", "source": "conv1", "target": "end" }
  ]
}`}
/>
