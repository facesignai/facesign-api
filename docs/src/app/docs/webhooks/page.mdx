## Overview

Webhooks notify your backend about changes in session state. Fetch the session after receiving webhooks.

<Callout type="info">FaceSign sends POST requests to your webhook URL when a session changes status.</Callout>

## Example event payload

<CodeTabs codeExamples={{
  javascript: '{\n  "type": "session.updated",\n  "data": { "id": "sess_123", "status": "completed" }\n}',
}} />

## Configure a webhook

<CodeTabs codeExamples={{
  curl: 'curl -X POST https://api.dev.facesign.ai/webhooks \\\n  -H "Authorization: Bearer YOUR_API_KEY" \\\n  -H "Content-Type: application/json" \\\n  -d "{\\"url\\": \\\"https://example.com/webhooks/facesign\\\"}"',
}} />
