## When to use sessions

Sessions represent a single verification attempt. They are short‑lived and scoped to a flow and user context.

<Callout type="info">Sessions should be created server‑side and handed to your client using a client secret.</Callout>

## Create a session

<CodeTabs codeExamples={{
  curl: 'curl -X POST https://api.dev.facesign.ai/sessions \\\n  -H "Authorization: Bearer YOUR_API_KEY" \\\n  -H "Content-Type: application/json" \\\n  -d "{\\"flowId\\": \\\"flow_basic\\\"}"',
  javascript: 'import { FaceSign } from "@facesignai/api"\n\nconst fs = new FaceSign({ apiKey: process.env.FACESIGN_API_KEY! })\nconst session = await fs.sessions.create({ flowId: "flow_basic" })',
  python: 'from facesign import FaceSign\n\nfs = FaceSign(api_key=FACESIGN_API_KEY)\nsession = fs.sessions.create({"flowId": "flow_basic"})',
  go: 'client := facesign.NewClient(os.Getenv("FACESIGN_API_KEY"))\nsession, err := client.Sessions.Create(ctx, facesign.CreateSessionRequest{FlowID: "flow_basic"})',
}} />

## Retrieve a session

<CodeTabs codeExamples={{
  curl: 'curl https://api.dev.facesign.ai/sessions/{SESSION_ID} -H "Authorization: Bearer YOUR_API_KEY"',
