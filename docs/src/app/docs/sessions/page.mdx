## When to use sessions

Sessions represent a single verification attempt. They are short‑lived and scoped to a flow and user context.

<Blockquote.Root variant="subtle" colorPalette="gray">
  <Blockquote.Content>
    Sessions should be created server‑side and handed to your client using a client secret.
  </Blockquote.Content>
  
</Blockquote.Root>

## Create a session

<CodeTabs codeExamples={{
  curl: 'curl -X POST https://api.dev.facesign.ai/sessions \\\n  -H "Authorization: Bearer YOUR_API_KEY" \\\n  -H "Content-Type: application/json" \\\n  -d "{\\"flowId\\": \\\"flow_basic\\\"}"',
  javascript: 'import { FaceSign } from "@facesignai/api"\n\nconst fs = new FaceSign({ apiKey: process.env.FACESIGN_API_KEY! })\nconst session = await fs.sessions.create({ flowId: "flow_basic" })',
  python: 'from facesign import FaceSign\n\nfs = FaceSign(api_key=FACESIGN_API_KEY)\nsession = fs.sessions.create({"flowId": "flow_basic"})',
  go: 'client := facesign.NewClient(os.Getenv("FACESIGN_API_KEY"))\nsession, err := client.Sessions.Create(ctx, facesign.CreateSessionRequest{FlowID: "flow_basic"})',
}} />

## Retrieve a session

<CodeTabs codeExamples={{
  curl: 'curl https://api.dev.facesign.ai/sessions/{SESSION_ID} -H "Authorization: Bearer YOUR_API_KEY"',

## Session object

### Top-level attributes

<Properties>
  <Property name="id" type="string">
    Unique identifier for the session (e.g., `"sess_abc123"`).
  </Property>
  <Property name="createdAt" type="number">
    Unix timestamp (milliseconds) when the session was created.
  </Property>
  <Property name="startedAt" type="number" nullable>
    Unix timestamp when the user started the verification flow. Null if not started yet.
  </Property>
  <Property name="finishedAt" type="number" nullable>
    Unix timestamp when the session finished or was canceled. Null if still in progress.
  </Property>
  <Property name="status" type="string">
    Current session status: `created`, `inProgress`, `incomplete`, or `complete`.
  </Property>
  <Property name="settings" type="object">
    SessionSettings object containing flow configuration and metadata. See below for details.
  </Property>
  <Property name="version" type="string" nullable>
    API version used for this session (e.g., `"2024-12-18"`).
  </Property>
  <Property name="report" type="object" nullable>
    SessionReport object with verification results. Only present when status is `complete`. See below for details.
  </Property>
</Properties>

### Session Status Lifecycle

Sessions progress through these statuses during the verification process:

- **`created`** - Customer has created the session, but user hasn't opened the URL yet
- **`inProgress`** - User started interaction with FaceSign
- **`incomplete`** - User closed browser tab before flow ended
- **`complete`** - User completed the flow, end node reached

The typical flow is: `created` → `inProgress` → `complete`

### SessionSettings object

The `settings` object contains the flow configuration and metadata for the session.

<Properties>
  <Property name="clientReferenceId" type="string" nullable>
    Your internal reference ID for this verification (e.g., your user ID).
  </Property>
  <Property name="metadata" type="object">
    Custom key-value pairs you attached to the session. Optional but recommended for tracking.
  </Property>
  <Property name="flow" type="array">
    Array of flow nodes that define the avatar behavior and session logic. See [Custom Flows](/flows) for details.
  </Property>
  <Property name="providedData" type="object" nullable>
    Pre-filled user data (name, email, phone, etc.) provided when creating the session.
  </Property>
  <Property name="avatarId" type="string" nullable>
    ID of the AI avatar used in conversation nodes.
  </Property>
  <Property name="langs" type="array" nullable>
    Array of supported language codes (e.g., `["en", "es", "fr"]`).
  </Property>
  <Property name="defaultLang" type="string" nullable>
    Default language code (e.g., `"en"`).
  </Property>
  <Property name="zone" type="string" nullable>
    Data residency zone: `"es"` (Spain) or `"eu"` (Europe).
  </Property>
  <Property name="customization" type="object" nullable>
    UI customization options for permissions page and controls. See [Customization](/customization).
  </Property>
  <Property name="videoAIAnalysisEnabled" type="boolean" nullable>
    Whether AI video analysis is enabled for this session.
  </Property>
</Properties>

<h3 id="sessionreport-object">SessionReport object</h3>

The `report` object contains verification results and is only present when the session status is `complete`.

<Properties>
  <Property name="transcript" type="array">
    Array of conversation messages exchanged during the session. Each message has `role`, `text`, and `timestamp`.
  </Property>
  <Property name="aiAnalysis" type="object" nullable>
    AI analysis results including sentiment, confidence scores, and behavioral insights.
  </Property>
  <Property name="location" type="object" nullable>
    User's location data including country, region, city, and coordinates.
  </Property>
  <Property name="device" type="object" nullable>
    Device information including browser, OS, and device type.
  </Property>
  <Property name="lang" type="string" nullable>
    Language code used during the session.
  </Property>
  <Property name="nodeReports" type="array" nullable>
    Array of node execution reports. Each report contains `nodeId`, `nodeType`, `outcome`, `timestamp`, and node-specific `data` (e.g., extracted document fields, face matching scores).
  </Property>
  <Property name="videoAIAnalysis" type="object" nullable>
    Video AI analysis results if `videoAIAnalysisEnabled` was true. Includes behavioral insights and fraud detection signals.
  </Property>
</Properties>
