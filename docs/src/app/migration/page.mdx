### Migration Steps

#### Step 1: Update Node Type References

<SimpleCodeBlock
  title="Before"
  language="typescript"
  code={`// Old approach
const twoFactorNode = {
  id: "2fa_node",
  type: FSNodeType.TWO_FACTOR,
  config: {
    method: "sms",  // or "email"
    length: 6,
    expiry: 300
  }
}`}
/>

<SimpleCodeBlock
  title="After"
  language="typescript"
  code={`// New approach - SMS
const smsNode = {
  id: "2fa_sms_node",
  type: FSNodeType.TWO_FACTOR_SMS,
  length: 6,
  expiry: 300,
  phoneNumberE164: "+1234567890"
}

// New approach - Email
const emailNode = {
  id: "2fa_email_node",
  type: FSNodeType.TWO_FACTOR_EMAIL,
  length: 6,
  expiry: 300,
  emailTo: "user@example.com",
  emailTemplate: "verification_code",
  fromName: "FaceSign",
  subject: "Your verification code"
}`}
/>

#### Step 2: Update Type Guards

<SimpleCodeBlock
  title="Type Checking"
  language="typescript"
  code={`// Check for either two-factor type
if (node.type === FSNodeType.TWO_FACTOR_EMAIL ||
    node.type === FSNodeType.TWO_FACTOR_SMS) {
  // Handle two-factor nodes
}

// Type-specific handling
switch (node.type) {
  case FSNodeType.TWO_FACTOR_EMAIL:
    // Handle email-specific logic
    break;
  case FSNodeType.TWO_FACTOR_SMS:
    // Handle SMS-specific logic
    break;
}`}
/>

#### Step 3: Update Flow Exports

If you have existing flows exported from Flow Designer before v1.0.18:

1. Replace `"type": "two_factor"` with either `"two_factor_email"` or `"two_factor_sms"`
2. Remove the `config.method` field
3. Add type-specific fields as needed

### Removed Fields

The following field has been removed as it was never implemented:

- `testMode` - This field was documented but never functional. Remove any references to it.

## Timestamp Format

<Alert.Root status="info" variant="subtle" my={6}>
  <Alert.Indicator />
  <Alert.Content>
    <Alert.Title>Important: Milliseconds Not Seconds</Alert.Title>
    <Alert.Description>
      All timestamps in the FaceSign API use Unix time in <strong>milliseconds</strong>, not seconds.
      This applies to createdAt, updatedAt, expireAt, and all other timestamp fields.
    </Alert.Description>
  </Alert.Content>
</Alert.Root>

### Conversion Examples

<SimpleCodeBlock
  languageSwitcher="tabs"
  codeExamples={{
    javascript: `// JavaScript - already in milliseconds
const now = Date.now()  // 1761594651878
const date = new Date(session.createdAt)  // Direct use

// If you have seconds, convert:
const seconds = 1761594651
const milliseconds = seconds * 1000`,
    python: `# Python - convert to milliseconds
import time

# Current time in milliseconds
now_ms = int(time.time() * 1000)  # 1761594651878

# Convert from API timestamp
from datetime import datetime
created_at = datetime.fromtimestamp(session['createdAt'] / 1000)

# If you have seconds, convert:
seconds = 1761594651
milliseconds = seconds * 1000`,
    go: `// Go - convert to milliseconds
import "time"

// Current time in milliseconds
nowMs := time.Now().UnixMilli()  // 1761594651878

// Convert from API timestamp
createdAt := time.UnixMilli(session.CreatedAt)

// If you have seconds, convert:
seconds := int64(1761594651)
milliseconds := seconds * 1000`
  }}
