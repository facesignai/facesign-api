## Using API Keys

### Setting Environment Variables

<SimpleCodeBlock
  title="Local Development (.env file)"
  language="bash"
  code={`# Sandbox/Development
FACESIGN_API_KEY=sk_test_your_test_key_here

# Production (use separate .env.production)
FACESIGN_API_KEY=sk_live_your_production_key_here`}
/>

### SDK Configuration

<SimpleCodeBlock
  defaultLanguage="javascript"
  languageSwitcher="tabs"
  codeExamples={{
    javascript: `import { Client } from '@facesignai/api'

// Automatically uses correct base URL based on key type
const client = new Client({
  auth: process.env.FACESIGN_API_KEY,
  // Optional: explicitly set base URL
  serverUrl: process.env.NODE_ENV === 'production'
    ? 'https://api.facesign.ai'
    : 'https://api.dev.facesign.ai'
})`,
    python: `import os
import facesignai

# Configure client with API key
client = facesignai.Client(
    auth=os.environ.get('FACESIGN_API_KEY'),
    # Optional: explicitly set base URL
    base_url='https://api.dev.facesign.ai' if 'test' in os.environ.get('FACESIGN_API_KEY', '') else 'https://api.facesign.ai'
)`,
    go: `import (
    "os"
    facesign "github.com/facesignai/go-sdk"
)

// Configure client
client := facesign.NewClient(
    facesign.WithAPIKey(os.Getenv("FACESIGN_API_KEY")),
    // Optional: explicitly set base URL
    facesign.WithBaseURL("https://api.dev.facesign.ai"),
)`
  }}
/>

### Direct API Calls

<SimpleCodeBlock
  title="Using with cURL"
  language="bash"
  code={`# Sandbox environment
curl -X POST https://api.dev.facesign.ai/sessions \\
  -H "Authorization: Bearer $FACESIGN_API_KEY" \\
  -H "Content-Type: application/json" \\
  -d '{"flow": {...}}'

# Production environment
curl -X POST https://api.facesign.ai/sessions \\
  -H "Authorization: Bearer $FACESIGN_API_KEY" \\
  -H "Content-Type: application/json" \\
  -d '{"flow": {...}}'`}
/>

## Key Management

### Rotating Keys

It's recommended to rotate your API keys periodically:

1. Generate a new key in your dashboard
2. Update your application to use the new key
3. Verify the new key is working
4. Deactivate the old key

### Revoking Keys

If a key is compromised:

1. Immediately revoke the key in your dashboard
2. Generate a new key
3. Update all applications using the compromised key
4. Review API logs for any unauthorized usage
