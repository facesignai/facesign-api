# Authentication

The FaceSign API uses API keys to authenticate requests. You can view and manage your API keys in the FaceSign Dashboard. {{ className: 'lead' }}

## API Keys

FaceSign provides two types of API keys:

- **Test mode keys** - Start with `sk_test_` and can be used for development and testing
- **Production mode keys** - Start with `sk_live_` and should be used in your production environment

<Note>
  Test mode keys have the same capabilities as production keys but will not charge your account. All sessions created in test mode are clearly marked.
</Note>

## Getting your API keys

1. Log in to your FaceSign Dashboard
2. Navigate to **Settings** → **API Keys**
3. Copy your API key for the appropriate environment

<Warning>
  Keep your API keys secure! Never commit them to version control or expose them in client-side code.
</Warning>

## Using API keys

Include your API key in the `Authorization` header of every request:

<CodeGroup>

```bash {{ title: 'cURL' }}
curl https://api.facesign.ai/v1/sessions \
  -H "Authorization: Bearer sk_test_4eC39HqLyjWDarjtT1zdp7dc"
```

```typescript {{ title: 'TypeScript' }}
import { FaceSign } from '@facesign/sdk';

const facesign = new FaceSign({
  apiKey: 'sk_test_4eC39HqLyjWDarjtT1zdp7dc',
});
```

```python {{ title: 'Python' }}
import facesign

facesign.api_key = 'sk_test_4eC39HqLyjWDarjtT1zdp7dc'
```

</CodeGroup>

<CollapsibleSection title="Environment Variables" defaultOpen>

We strongly recommend using environment variables to store your API keys:

<CodeGroup>

```bash {{ title: '.env' }}
FACESIGN_API_KEY=sk_test_4eC39HqLyjWDarjtT1zdp7dc
```

```typescript {{ title: 'TypeScript' }}
import { FaceSign } from '@facesign/sdk';

const facesign = new FaceSign({
  apiKey: process.env.FACESIGN_API_KEY,
});
```

```python {{ title: 'Python' }}
import os
import facesign

facesign.api_key = os.environ.get('FACESIGN_API_KEY')
```

</CodeGroup>

</CollapsibleSection>

## Client-side authentication

For client-side integrations, use session-specific client secrets instead of your API key:

```typescript {{ title: 'Client-side' }}
// Never use your API key on the client side!
// Use the client_secret from a session instead
const clientSecret = 'vs_1a2b3c4d5e6f_secret_abc123';

// Initialize the client-side SDK
const facesignClient = new FaceSignClient({
  clientSecret: clientSecret,
});
```

## Rate limiting

API requests are rate limited to ensure fair usage:

- **Test mode**: 100 requests per minute
- **Production mode**: 1000 requests per minute

If you exceed the rate limit, you'll receive a `429 Too Many Requests` response:

```json {{ title: 'Rate limit error' }}
{
  "error": {
    "type": "rate_limit_error",
    "message": "Too many requests. Please retry after 60 seconds."
  }
}
```

## API versioning

The FaceSign API uses date-based versioning. You can specify the API version using the `FaceSign-Version` header:

```bash {{ title: 'Specify API version' }}
curl https://api.facesign.ai/v1/sessions \
  -H "Authorization: Bearer sk_test_..." \
  -H "FaceSign-Version: 2024-01-15"
```

<Note>
  If you don't specify a version, your requests will use the API version that was current when your account was created.
</Note>

<CollapsibleSection title="Security Best Practices" variant="subtle">

1. **Never expose your API keys** - Keep them server-side only
2. **Use environment variables** - Don't hardcode keys in your source code
3. **Rotate keys regularly** - Generate new keys periodically
4. **Use test keys for development** - Keep production keys secure
5. **Monitor key usage** - Check your dashboard for unusual activity

<Warning>
  API keys provide complete access to your FaceSign account. Treat them like passwords and keep them secure.
</Warning>

</CollapsibleSection>

## Webhook signatures

For webhook endpoints, verify the signature to ensure requests are from FaceSign:

<CodeGroup>

```typescript {{ title: 'TypeScript' }}
import crypto from 'crypto';

function verifyWebhookSignature(
  payload: string,
  signature: string,
  secret: string
): boolean {
  const expectedSignature = crypto
    .createHmac('sha256', secret)
    .update(payload)
    .digest('hex');
  
  return crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(expectedSignature)
  );
}
```

```python {{ title: 'Python' }}
import hmac
import hashlib

def verify_webhook_signature(payload, signature, secret):
    expected_signature = hmac.new(
        secret.encode('utf-8'),
        payload.encode('utf-8'),
        hashlib.sha256
    ).hexdigest()
    
    return hmac.compare_digest(signature, expected_signature)
```

</CodeGroup>
