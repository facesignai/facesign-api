## Key Features

### 🤖 Conversational AI
Build natural verification flows with AI-powered avatars that guide users through the process.

### 🔐 Biometric Security
Implement face scanning, liveness detection, and 1:1 facial matching for secure authentication.

### 📄 Document Verification
Scan and verify government IDs, passports, and other documents with advanced OCR.

### 🔄 Flow Control
Create complex verification flows with conditional logic, branching, and data validation.

### 🌍 Multi-Language Support
Support users globally with built-in internationalization capabilities.

### 🎨 Customizable UI
Tailor the verification experience to match your brand and requirements.

## Installation

```bash
npm install @facesignai/api
# or
yarn add @facesignai/api
```

## Basic Example

```typescript
import Client from '@facesignai/api'

// Initialize the client
const client = new Client({
  auth: process.env.FACESIGN_API_KEY
})

// Create a verification session
const { session, clientSecret } = await client.session.create({
  clientReferenceId: 'user-123',
  flow: {
    nodes: [
      { id: 'start', type: 'start' },
      { 
        id: 'conversation', 
        type: 'conversation',
        prompt: 'Welcome! Please tell me your name.',
        transitions: []
      },
      { id: 'end', type: 'end' }
    ],
    edges: [
      { id: 'e1', source: 'start', target: 'conversation' },
      { id: 'e2', source: 'conversation', target: 'end' }
    ]
  }
})

console.log('Session URL:', clientSecret.url)
```
