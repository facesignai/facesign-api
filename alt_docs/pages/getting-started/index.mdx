# Getting Started

Welcome to the FaceSign API! This guide will help you get started with integrating FaceSign into your application.

## What You'll Need

- A FaceSign account ([Sign up here](https://dashboard.facesign.ai))
- Node.js 12 or higher
- Basic knowledge of JavaScript/TypeScript

## Quick Steps

1. **[Install the SDK](/getting-started/installation)** - Add the FaceSign SDK to your project
2. **[Set up authentication](/getting-started/authentication)** - Configure your API key
3. **[Create your first session](/getting-started/quick-start)** - Build a simple verification flow
4. **[Handle errors](/getting-started/error-handling)** - Learn about error handling
5. **[Configure your environment](/getting-started/environment-setup)** - Set up for development and production
