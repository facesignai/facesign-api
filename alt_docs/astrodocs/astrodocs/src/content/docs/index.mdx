## Features

- **Conversational AI** - Natural language interactions powered by advanced AI
- **Biometric Verification** - Face scanning, liveness detection, and 1:1 matching
- **Document Scanning** - Support for passports, IDs, driver's licenses, and more
- **Multi-Factor Authentication** - Email and SMS verification with customizable templates
- **Flexible Flows** - Build custom verification workflows with our node-based system
- **Real-time Updates** - Webhooks for session status changes and completions

## Authentication

All API requests require authentication using Bearer tokens:

```bash
Authorization: Bearer sk_live_your_api_key
```

Use test mode keys (`sk_test_*`) for development and live mode keys (`sk_live_*`) for production.
